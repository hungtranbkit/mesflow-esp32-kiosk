# GM65 scheduled input window — software-only prototype

This branch does **not** turn the scanner off, sleep it, dim its illumination, or save scanner power. It suppresses scanner UART input while leaving keypad, LCD and MESFlow servicing in the normal main loop. It is not a substitute for the requested physical scanner rest. The M910 profile connects scanner TX to ESP GPIO44 RX and does not provide a verified ESP TX or scanner power control. The GROW GM65 V1.3 manual documents a sleep control at zone 0x00D9 and UART wake; it requires a properly wired and validated ESP-to-GM65 receive path, correct levels and hardware verification. A controlled power switch requires an identified compatible GPIO, switch and power-on validation. Neither has been verified on 39:84.

The prototype defaults to enabled, 22:00 inclusive to 06:00 exclusive, Asia/Ho_Chi_Minh (UTC+7). Without valid system time (epoch before 2024), input is allowed. Each normal scanner poll recomputes the state from current wall time, including after reboot, reconnect and clock jumps; partial frames are discarded on transitions. It drains UART bytes during the window without processing them; this cannot prove scanner sleep. USB console commands `scanner-window off` and `scanner-window on HH:MM HH:MM` persist configuration under `scanner_rest`; `status` shows mode and clock validity. Equal start/end is rejected. Clock validity detects unsynchronized boot, not a plausibly wrong synchronized clock. Serial `scanner-baud` and keypad operations remain separate.

Host policy tests cover boundaries, invalid clock, daytime windows, clock jumps, boot calculation and unsigned monotonic arithmetic. Firmware build and device verification status must be recorded separately. Do not deploy this prototype to production or represent it as hardware sleep without proven wiring, device-level sleep/wake and recovery tests. On 39:84 the existing scanner RX itself is unverified and the board has one app slot; do not sacrifice the working diagnostic image solely to claim a test of physical rest.

Manual: https://www.sunrom.com/download/767.pdf#page=49 (printed p. 45–46); https://www.sunrom.com/download/767.pdf#page=34 (serial command framing).
